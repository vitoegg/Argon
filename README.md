# Argon

A trimmed LuCI theme for OpenWrt 25.12, based on [luci-theme-argon](https://github.com/jerrykuku/luci-theme-argon): fixed dark mode, fixed left-side login and a lighter package.

## Package

- `luci-theme-argon` - Based on upstream v2.4.7 ([ddefe5f](https://github.com/jerrykuku/luci-theme-argon/commit/ddefe5f05ca334dba10d2d65d25ebf14e986ee88)). All changes from upstream are listed in [UPSTREAM.md](UPSTREAM.md).
